# 從菜雞到股神 V4｜完整新手教學系統

## 產品目標

讓一個完全不懂股票、不懂 K 線的人，完成課程後能打開陌生 K 線圖，依固定順序自己判讀：

**K 棒 → 價格 → 高低點 → 趨勢 → 位置 → 支撐壓力 → 量價 → 指標 → 反轉/突破證據 → 進場 → 失策 → 空間 → 等待/放棄。**

不是背名詞、不是猜漲跌、不是投資建議。

---

## 最高優先級教學規則

每一個新能力都固定走：

1. **先教**：只新增一個新觀念，直接把答案位置標清楚。
2. **示範**：換一張圖，由系統一步一步指出為什麼。
3. **有提示練習**：保留必要線索，但不能把答案名稱直接寫在圖上。
4. **少提示練習**：只保留讀圖所需資訊。
5. **無提示練習**：玩家自己判斷。
6. **立即解析**：錯了要說明「看錯哪個證據」，不能只顯示答錯。
7. **最後才考**：沒有在前面明確教過、示範過、練過的內容，不得出現在測驗。

硬規則：**先教，才考。一次只多一件事。**

## 圖表與價位硬規格

### 台股合法跳動單位

所有「可交易價位」必須落在合法 tick：

- < 10 元：0.01
- 10 ～ < 50 元：0.05
- 50 ～ < 100 元：0.1
- 100 ～ < 500 元：0.5
- 500 ～ < 1000 元：1
- >= 1000 元：5

價位軸不可顯示實際不會出現的交易價位。支撐/壓力核心、進場、失策、停損等可交易價位也要 snap 到合法 tick；MA、MACD 等純計算指標數值不受此限制，但不得冒充可下單價格。

### 精確價格題

凡題目要求玩家選一個精確價錢：

- 該價位一定要能直接從圖上讀到。
- 題目選項是 62.5 / 64 / 66.5，圖上就必須出現對應可讀價位，不得只靠相對高度猜。
- 練習時可用中性水平 guide + 數字；不得在 guide 上寫「答案／支撐／最高價」等洩題字樣。
- 玩家日後直接點圖選價時，要顯示水平游標 + 即時價格，並吸附合法 tick。

### 防洩題

- 教學示範可以寫「開盤／收盤／最高／最低」。
- 一進入練習，答案語意標籤必須消失，只保留必要數字與中性圖形。
- 點 K 棒不能用 tooltip 把當題正在考的完整答案直接顯示出來。
- 支撐題不能在練習階段直接畫一塊寫著「支撐候選」的答案區。
- 假突破題不能在練習階段直接寫「跌回區間／假突破」等結論。

## 課程順序

### MODULE A｜真的看懂一根 K

1. 一根 K 代表一段時間。
2. 開、高、低、收 OHLC。
3. 實體與影線。
4. 紅 K / 綠 K：只比較開盤與收盤。
5. 日漲跌：今日收盤與昨收，和 K 棒顏色是兩件事。
6. 價位軸怎麼讀。
7. 台股一檔／一跳（tick size）。
8. 日 K、週 K、月 K、分 K 的差別。
9. 單根長紅、長黑、十字、長上下影的描述能力；明確強調單根 K 不是買賣訊號。

### MODULE B｜從一根看到一段

10. 兩根 K 的高低關係。
11. 連續收盤往上／往下。
12. 找局部高點 Swing High。
13. 找局部低點 Swing Low。
14. Higher High / Higher Low。
15. Lower High / Lower Low。
16. 上升、下降、盤整。
17. 「跌很多」不等於反轉。
18. 結構改變需要證據。

### MODULE C｜位置與自己畫線

19. 支撐先看現象，再命名。
20. 壓力先看現象，再命名。
21. 支撐／壓力是區域，不是神奇單點。
22. 區間上緣／下緣。
23. 前高前低的角色。
24. 壓力突破後可能轉支撐。
25. 玩家第一次自己畫水平支撐。
26. 玩家自己畫水平壓力。
27. 系統以「合理區域」評分，不要求一毛不差。
28. 找出錯線：硬穿 K 棒、只為配合結論的線。
29. 之後才教斜趨勢線。

### MODULE D｜量與均線

30. 成交量和自己的近期平均比。
31. 價漲量增、價跌量增、縮量整理。
32. 爆量不是自動利多。
33. MA20 是什麼。
34. 價格在 MA20 上／下。
35. MA20 方向與斜率。
36. 乖離：離平均成本區太遠的風險。
37. MA60 與短中期排列。
38. 均線交叉不是自動買點。

### MODULE E｜MACD / KD / RSI

先分開教，再組合；價格結構永遠優先。

39. MACD：DIF、DEA、柱狀體先認圖。
40. MACD 零軸與動能增加／減弱。
41. MACD 背離；背離是警訊，不是立刻反轉。
42. KD：K、D、20/80 區域。
43. KD 黃金／死亡交叉。
44. KD 高檔/低檔鈍化：80 以上不等於立刻賣、20 以下不等於立刻買。
45. RSI：強弱與超買超賣。
46. RSI 背離。
47. 指標衝突：KD 金叉但價格仍破底時怎麼看。
48. 指標的定位：**輔助證據，不是答案。**

### MODULE F｜反轉、突破與進場

49. 止跌不等於反轉。
50. 不再破低。
51. Higher Low。
52. 突破關鍵前高，反轉證據增加。
53. 觸碰壓力 vs 收盤突破。
54. 假突破。
55. 突破後回測。
56. 回測守住再轉強。
57. 突破直接進 vs 回測進：比較位置與代價，不教唯一神奇買點。
58. 「現在根本不能買」可以是滿分答案。

### MODULE G｜決策與風險

59. 進場前先找失策點：哪裡代表原本論點錯了。
60. 下一個壓力決定上方空間，不先許願固定 +15%。
61. R:R。
62. 部位大小隨失策距離調整。
63. 追高與乖離。
64. 續抱：理由仍成立。
65. 退出：理由失效。
66. 結果賺錢 ≠ 決策一定正確。
67. 結果虧損 ≠ 決策一定錯。
68. 證據互相矛盾時，等待也是決策。

### MODULE H｜完整聯合判讀

不再問「這題在考 MACD 還是支撐」。玩家自己決定先看什麼。

固定掃描順序：

1. 現在是什麼市場結構？
2. 關鍵高低點在哪？
3. 支撐／壓力在哪？
4. 現在的位置好不好？
5. 量是否支持？
6. MA / MACD / KD / RSI 是否確認或衝突？
7. 有沒有反轉／突破證據？
8. 如果進場，哪裡代表我錯？
9. 上方空間夠不夠？
10. 最後才選：進場／等待／放棄。

## 最終模式｜逐日 K 線實戰

這是畢業測驗，不放在前面教學。

- 初始只顯示截至 D0 的資料，未來完全遮住。
- 玩家先畫線、判斷趨勢與位置。
- 選擇：等待／觀察／進場／放棄。
- 若進場，先設定進場與失策價。
- 按「下一日」只揭曉下一根 K。
- 每一天重新問：原判斷還成立嗎？要維持、等待、退出還是放棄？
- 不允許事後一次看到完整未來。

### 最終評分

不能只看最後 P/L；至少分成：

- 結構判讀
- 畫線合理度
- 證據完整度
- 進場品質
- 失策點合理度
- 風險報酬
- 是否過早／追高
- 是否在證據不足時亂交易
- 紀律

允許：

- **賺錢但決策品質低**
- **虧損但決策品質高**

目標是訓練可重複的判斷流程，不是獎勵猜中一次漲跌。
