# Visible progress checklist

- 0B Industry: completed/1224, unresolved, this-run success/fail, throttle, TIP cache hits, artifact id.
- 0C Company/Fundamental: source inventory count, PIT-audited datasets count, coverage dates, unresolved source/lineage gates, artifact id.
- 0D Macro: source series count, audited/equivalent series count, coverage/publication-lag gates, unresolved series, artifact id.
- 0E Event/Time: source inventory count, reconstructible-PIT source count, rejected/live-only source count, unresolved audits, artifact id.
- Dashboard: each lane shows status, % when denominator is meaningful, effective new work, blocker and last update.

No lane may disappear from the dashboard while another lane is running.
